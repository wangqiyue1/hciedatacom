# 🧩 HCIE 拖拽滑块答题系统 (HCIE Drag & Drop Quiz)

> 专为华为 HCIE / 华为网络认证考试打造的**拖动滑块答题练习系统**！
> 还原真实考试界面的滑块拖拽交互，纯前端静态运行，已内置 **54 道核心拖拽/匹配真题**，开箱即练！

---

## ✨ 核心特性

- 🎯 **真实考试拖拽滑块交互**：
  - **待选滑块池**：微立体高亮蓝色芯片卡片，带有防滑抓手图标 `⠿`，支持滑块乱序；
  - **目标槽位区**：对应每项描述提供独立的接收槽（Drop Zone）；
  - **双模拖放操作**：
    - **原生拖拽**：支持电脑鼠标拖动、手机触屏手势滑动（Touch Drag）；
    - **免拖动快捷放入**：手机上直接“点击滑块选中 ➔ 点击目标槽位放入”，灵敏轻巧；
    - **归位与替换**：槽位支持单个滑块退回，顶部提供一键“全部归位”重置按钮。
- ⚡ **即时判分与解析**：
  - 提交后槽位精准变色（正确绿色 `✔`，错误红色 `✘` 并展开提示正确答案）；
  - 错题自动存入错题本，可在首页开启“错题专练”；
  - 开启“答对自动跳下一题”，全对秒切，错题驻留看解析。
- 📦 **开箱即用，零门槛部署**：
  - 打开网页直接内置 54 道 HCIE 拖拽真题，无需手动导入文件，零等待！
  - 所有文件体积只有几十 KB，绝无任何 GitHub 25MB 上传限制！

## 🚀 部署到 GitHub Pages（30秒完成）

1. 在你的 GitHub 仓库（例如 `hciedatacom`）上传页面中；
2. **只需将本目录下的以下 6 个轻量文件拖入网页框中**：

| 文件名 | 说明 |
| :--- | :--- |
| **`index.html`** | 网页程序主入口（含图片放大灯箱与手机适配） |
| **`hcie_drag_bank.js`** | **54 道拖拽真题数据（已关联拓扑图路径）** |
| **`images/`** 文件夹 | **所有题目拓扑图、配置图（共 71 张，约 8MB，支持拖入上传）** |
| **`hcie_drag_bank.json`** | 拖拽真题 JSON 格式备份 |
| **`README.md`** | 仓库说明文档 |
| **`favicon.svg`** | 网站图标 |
| **`manifest.json`** | 手机全屏 PWA 支持 |

3. 点击底部绿色按钮 **「Commit changes」** 保存；
4. 进入仓库 **Settings** ➔ **Pages**，在 **Branch** 选择 **main**（或 master），点击 **Save**；
5. 稍等 1 分钟，你的专属在线拖拽刷题网址就上线了！

---

## 💻 本地直接运行

直接双击 `index.html` 或 `答题练习.html`，即可在浏览器中开始练习！无需任何安装。
