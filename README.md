# 📝 答题练习系统 (Quiz Master)

> 一个轻量、流畅、纯前端的现代化刷题与模拟考试系统。支持单选题、多选题，以及**真实认证考试（华为 HCIE / Pearson VUE）风格的拖动滑块匹配题**！
> 纯静态运行，无需后端服务器，零依赖，数据仅保存在用户本地浏览器（LocalStorage）。

---

## ✨ 核心特性

- 🎯 **考试级拖拽滑块答题**：
  - 待选滑块池 + 目标槽位匹配区；
  - 双模交互：支持电脑鼠标拖放、手机触屏长按拖动（Touch Drag），以及免拖动的“点击选中 + 点击放入”；
  - 槽位实时对错标记（✔/✘）与正确答案对照提示；
  - 支持一键“全部归位”重置。
- 📚 **全题型支持**：
  - 单选题、多选题、拖拽连线/匹配题。
- 🧠 **错题智能收录与巩固**：
  - 答错题目自动进入错题本，可在首页进行“错题练习”专项攻关，答对自动移出错题。
- ⚙️ **灵活练习设置**：
  - 选项 / 滑块乱序（打破死记硬背位置）；
  - 答对自动跳下一题（全对时无缝秒切，答错停留看解析）；
  - 题目顺序打乱。
- 📦 **快捷题库导入与导出**：
  - 支持 **TXT 文本** 批量导入（支持简单直观的 `A → B` 拖拽格式与选择题格式）；
  - 支持 **JSON** 格式导入与导出备份；
  - 内置真实华为认证拖拽题示例，一键载入开箱即用。
- 📱 **移动端优化与 PWA 支持**：
  - 适配手机、平板、电脑各种屏幕尺寸；
  - 完美适配系统深色模式（Dark Mode）；
  - 支持“添加到主屏幕”全屏独立沉浸答题。

## 🚀 部署到 GitHub Pages（3步极速上线）

你可以直接将本项目免费发布在 GitHub Pages 上供自己或他人在线刷题：

### 第 1 步：创建 GitHub 仓库并上传代码
1. 在 GitHub 上新建一个仓库（例如叫 `quiz-app`），选择 **Public**（公开）；
2. 在本地项目目录下打开终端，执行以下命令初始化并推送：
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for quiz app with drag & drop support"
   git branch -M main
   git remote add origin https://github.com/你的用户名/你的仓库名.git
   git push -u origin main
   ```

### 第 2 步：开启 GitHub Pages
1. 打开你的 GitHub 仓库页面，点击顶部 **Settings**（设置）；
2. 在左侧菜单找到 **Pages**；
3. 在 **Build and deployment** 下：
   - **Source** 选择 **GitHub Actions**（仓库已内置自动化发布脚本）；
   - 或者选择 **Deploy from a branch**，Branch 选择 **main**，文件夹保持 **/ (root)**，点击 **Save**。

### 第 3 步：在线访问
等待 1~2 分钟部署完成后，页面顶部会显示你的专属访问链接：
`https://<你的用户名>.github.io/<你的仓库名>/`

## 📝 题库格式编写指南

### 1. 拖拽/滑块匹配题（TXT 推荐）
使用箭头「→」或「->」连接左侧滑块与右侧目标：
```text
1.【拖拽题】请将HTTP状态码和原因短语进行匹配
1XX → 请求被接收
2XX → 请求成功
3XX → 进一步操作需要被执行
4XX → 请求错误
5XX → 服务端错误
解析：1XX为信息类，2XX为成功类，3XX为重定向...
```

### 2. 选择题（单选/多选）
```text
1. 世界上最高的山峰是？
A. 乞力马扎罗山
B. 珠穆朗玛峰
C. 阿尔卑斯山
D. 富士山
答案：B
解析：珠穆朗玛峰是世界最高峰。

2. 下列属于中国直辖市的有？（多选）
A. 北京
B. 天津
C. 重庆
D. 深圳
答案：ABC
解析：四个直辖市为京、津、沪、渝。
```

### 3. JSON 格式
```json
[
  {
    "type": "drag",
    "q": "请将HTTP状态码和原因短语进行匹配",
    "pairs": [
      { "left": "1XX", "right": "请求被接收" },
      { "left": "2XX", "right": "请求成功" }
    ],
    "explanation": "解析内容..."
  },
  {
    "q": "世界上最高的山峰是？",
    "options": ["乞力马扎罗山", "珠穆朗玛峰", "阿尔卑斯山", "富士山"],
    "answer": "B",
    "explanation": "解析内容..."
  }
]
```

## 🔒 隐私与安全性
所有题库、练习进度、错题记录均采用浏览器的 `LocalStorage` 存储在用户本地设备，**不会上传到任何外部服务器**，完全保护你的题库私密性。
